# Changelog

## 0.1.0-alpha.1 — implementation preview

### Added
- Rust core, native CLI and browser WASM adapter.
- Five explicitly mathematical models, selection/draw modes and exact odds.
- Unbiased bounded sampling and partial Fisher–Yates subset generation.
- JSON record validation against the bundled registry; browser text/CSV export.
- Disabled official-rule candidates, explicit coverage gaps and source locations.
- GyLiber contribution, security, architecture and release documentation.
- Native and browser test suites; locked dependencies and pinned CI actions.

### Limitations
- No enabled official game profiles, add-on groups, sales, prizes or prediction.
- No public hosting, external audit, signed records or independent review claim.
- No stable release tag or completed client acceptance yet.
- Schema 1 verification is restricted to this exact software version.

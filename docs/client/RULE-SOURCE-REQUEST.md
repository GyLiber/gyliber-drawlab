Subject: Request for authoritative historical ITHUBA game rules and applicability

Dear NLC Information Centre,

Please route this enquiry to the team responsible for National Lottery game-rule
publications or historical records.

GyLiber is developing an educational mathematical lottery simulator. We need
complete authoritative ITHUBA rules for LOTTO / PLUS 1 / PLUS 2, PowerBall / PLUS,
and DAILY LOTTO / PLUS, including the 2025 editions and amendments affecting them.
Please provide accessible HTTPS publication links or lawfully shareable copies,
and identify the edition, approval/effective dates, applicable period, replacement
or withdrawal dates, and any supplementary rules needed to interpret each family.

We need to verify number pools, selection versus draw behavior, bonus/extra-ball
rules, PLUS relationships and the complete product catalogue for that period.
Please distinguish these historical rules from the succeeding operator's current
rules and advise the appropriate custodian if these documents are held elsewhere.
The previously located content-host PDFs could not be accessed securely; we will
not bypass certificate warnings. We seek factual implementation references, not
affiliation, certification or permission to operate a lottery.

Thank you,
Gyile / GyLiber

actual file bytes, edition, effective scope and exact page/section references.

search snippet is not evidence of applicability. Map each clause to a fixture;

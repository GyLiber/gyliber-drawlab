# DrawLab v0.2.0-alpha.1 — exact probability analysis

Laboratory prerelease for Gyile / GyLiber. Not a certified lottery system,
verified official-game implementation, ticket, prediction or prize estimate.

## Demonstrable capability

Open https://gyliber-drawlab.onrender.com/ and choose a mathematical model.
The main-match explorer shows exact probabilities and rounded visual bars.
Choose **Minimum main matches** to inspect the exact probability of at least that
many main matches in one independent draw. For 5/36, at least 3 is 4806 / 376992.
**Export probability table CSV** downloads all exact and cumulative fractions,
with the software version and profile ID. No data leaves the browser.

Native equivalent:

    drawlab at-least --profile lab-5of36 --matches 3

Generation, simulated draws, exact full-match odds and JSON record verification
remain available. Bonus/extra balls are excluded from the main-match explorer;
changing them does not change the main-only probability.

## Packages and integrity

- `drawlab-0.2.0-alpha.1-web.tar.gz`: static browser build; serve through an HTTP(S)
  server, not file://. Do not run the npm development server publicly.
- `drawlab-0.2.0-alpha.1-linux-x86_64.tar.gz`: Linux x86_64 CLI built on Ubuntu 24.04;
  requires a compatible Linux/glibc environment. Other targets build from source.
- `SHA256SUMS`: verify downloaded assets with `sha256sum -c SHA256SUMS` after
  downloading all listed files. Checksums detect changes relative to this list;
  they are not independent signatures or supply-chain attestations.
- Source archives are provided by GitHub for the release tag. Build prerequisites
  and the reserved-rights license remain in the repository.

## Compatibility and limits

Record schema remains version-specific: this verifier accepts 0.2.0-alpha.1
records; preserve older records with their matching earlier verifier.
Five laboratory models are enabled. Official ITHUBA candidates remain disabled
until complete rules, applicability and conformance evidence are reviewed.
No ticket sales, prizes, current-operator mapping or all-game claim is included.
No external security audit or certification has been completed.

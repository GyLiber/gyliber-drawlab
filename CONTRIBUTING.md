# Contributing to GyLiber DrawLab

Read README.md, docs/governance/DEVELOPMENT.md, docs/security/THREAT-MODEL.md,
and the architecture decisions before making a change.

Use Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, `chore:`.
Keep each commit coherent, each PR focused, and preserve corrective history.

Every change needs relevant verification and honest documentation of remaining
limitations. Never introduce secrets, private records or unlicensed assets.
AI-assisted work follows the same review and verification rules as other work.
The repository's license reserves rights to GyLiber; collaboration requires
owner authorization. Dependencies retain their own licenses.

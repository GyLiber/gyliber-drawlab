# Security reporting

Do not post vulnerabilities, secrets or exploit details in public issues.
Use the repository Security tab's private reporting option if enabled; otherwise
contact the owner through an already established private channel. The project
does not assert that private reporting has been enabled.

DrawLab is an educational simulator, not a certified lottery system. See
[threat model](docs/security/THREAT-MODEL.md). Supported security fixes initially
apply to the latest prerelease only. AI-generated changes require normal review.
